## Frequently Asked Questions (FAQ) ❓

**Is this a modification of the core game files?**
No. FishMaster Sovereign runs externally, through a screen overlay and input simulation. It does not rewrite memory blocks or alter the game's executable file structure. It relies completely on the standard inputs (mouse and keyboard) available to any player, ensuring a stable coexistence.

**How does it handle game updates?**
The utility normally operates on configurable coordinate baselines. After a major game patch, if the layout shifts, the Water Integrity Diagnostic can be re-run to recalibrate the visual anchors. Our team typically pushes a compatibility patch within 24 hours of a major game update, but your tolerance for vanilla play may be required for a brief moment.

**Can I use this while running a screen recorder?**
Absolutely. The overlay is lightweight and will not interfere with hardware encoding. Many of our users stream their gameplay, and the UI elements are designed to be visually pleasing for the audience as well.

## Troubleshooting Common Tide Troughs 🛠️

**The overlay appears but does not react to the game.**
This typically indicates that the Water Integrity Diagnostic was interrupted. Please ensure the game is running in Borderless Windowed or Exclusive Fullscreen mode, and re-run the calibration wizard. The tool needs a visual reference to anchor its coordinates.

**The fonts appear blurry.**
Navigate to the Display Settings within the overlay and adjust the UI Scale factor. The system now supports fractional scaling to better match retina displays.

**Data is not updating.**
Audio is a key input for the data synchronizer. Ensure your in-game sound is enabled and routed to the default device—even at low volume—so the sync can read the sonar cues.
